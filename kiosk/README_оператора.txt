1. ЧТО В ПАКЕТЕ
════════════════════════════════════════════════════════════
stand.html   — автодемо: циклический ролик 90 секунд, работает без оператора.
compare.html — «Сейчас / Будет»: интерактивное сравнение с разделителем.
model.html   — BIM-модель обследования (13 716 элементов, фильтры, поиск).
index.html   — полная презентация проекта (лонгрид с разделами).
assets/      — модель, изображения, шрифты, QR, аудио (всё локально,
               интернет на стенде НЕ нужен).
stand_demo.mp4 (если приложен) — видеофолбэк на случай слабого ПК.

════════════════════════════════════════════════════════════
2. ЗАПУСК
════════════════════════════════════════════════════════════
Windows:  двойной клик по  kiosk/start_kiosk_win.bat
Linux:    ./kiosk/start_kiosk_linux.sh

Откроется автодемо в полноэкранном режиме киоска.
Рекомендуемый экран: горизонтальный 16:9, 1920×1080 и выше.

Если ничего не запустилось вручную:
  1) python3 -m http.server 8377   (в папке проекта)
  2) открыть браузер: http://127.0.0.1:8377/stand.html  и нажать F11.

════════════════════════════════════════════════════════════
3. УПРАВЛЕНИЕ (тач-экран и клавиатура)
════════════════════════════════════════════════════════════
Касание экрана / Esc  — главное меню модулей проекта.
Клавиши 1–7           — переход к модулю прямо из меню.
Пробел                — пауза / продолжение автодемо.
Кнопка «Голос»        — голосовой комментарий (по умолчанию ВЫКЛ).

Бездействие 75 секунд на любом модуле — автоматический возврат
в автодемо (за 15 секунд появляется индикатор обратного отсчёта).
Курсор скрывается сам через 3 секунды без движения.

════════════════════════════════════════════════════════════
4. ГОЛОСОВОЙ КОММЕНТАРИЙ
════════════════════════════════════════════════════════════
Записанные диктором файлы voice_1.mp3 … voice_6.mp3 положить
в assets/audio/ (тексты — в файле kiosk/Тексты_для_диктора.txt).
Если файлов нет, кнопка показывает «Голос: нет файлов» — это норма,
демо работает в немом режиме с титрами.

════════════════════════════════════════════════════════════
5. ЕСЛИ ПК НЕ ТЯНЕТ 3D
════════════════════════════════════════════════════════════
Проиграть stand_demo.mp4 любым плеером в полноэкранном цикле
(например: vlc --loop --fullscreen stand_demo.mp4).
Содержание ролика полностью повторяет автодемо (без звука).
